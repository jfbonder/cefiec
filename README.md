# CEFIEC

Sitio web del Instituto de Investigaciones en Didáctica de las Ciencias Naturales y la Matemática (CeFIEC), Facultad de Ciencias Exactas y Naturales, UBA.

## Estructura

- `index.html` y demás `.html`: páginas del sitio nuevo.
- `assets/css/estilos.css`: estilos. **Los colores del sitio están todos al principio de este archivo**, en el bloque `:root`; para cambiar la paleta alcanza con modificar esas líneas.
- `assets/img/`: logos.
- `assets/js/menu.js`: menú desplegable para celulares.
- `original/`: páginas del sitio anterior (Joomla) recuperadas de Wayback Machine, y la página del CEFIEC de 2001 en PDF. Se conservan como fuente; no forman parte del sitio nuevo.

## Contenido para revisar

Gran parte del contenido viene del sitio anterior (último contenido entre 2020 y 2024) y puede estar desactualizado: autoridades, investigadores/as, cursos de posgrado, oportunidades y novedades.
